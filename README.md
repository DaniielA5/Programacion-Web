# Actividad 1 - Programación Web

Repositorio con los ejercicios prácticos del Tema 2 de la materia Programación Web (ITO).

Elaborado por Juarez Ramirez Daniel Alexis

## Contenido

- Ejercicio 1: Cree una página HTML con el clásico Hola Mundo!.
- Ejercicio 2: Utilice formatos básicos: `<p>`, `<strong>`, `<em>`, `<br>`.
- Ejercicio 3: Cree enlaces utilizando estos tres tipos: `<a href="url">`, `target="_blank"`, `target="_self"`.
- Ejercicio 4: Utilice el `img` para insertar imágenes básicas: `<img>`, `alt`, `width`.
- Ejercicio 5: Aquí ya combinamos el texto con los enlaces, `<img>` dentro de `<p>`.
- Ejercicio 6: Utilice `<header>`, `<section>`, `<footer>`.
- Ejercicio 7: Listas anidadas + enlaces `<ul>` `<ol>`.
- Ejercicio 8: Estructuras de tablas `<thead>` `<tbody>`.
- Ejercicio 9: Formulario aplicando: HTML, CSS...
- Ejercicio 10: Calculadora Celsius.
- Ejercicio 11: Aplicación web, aplicando HTML, JS y CSS.
- Ejercicio 12: Aplicación web, aplicando HTML, JS y CSS.
- Ejercicio 13: Aplicación web, aplicando HTML, JS y CSS.
- Ejercicio 14: Aplicando métodos importantes de arreglos.
- Ejercicio 15: Aplicando métodos importantes de POO.
- Ejercicio 16: Operaciones básicas utilizando funciones flecha en JavaScript.
- Ejercicio 17: Gestión de tareas pendientes con JSON, Local Storage, funciones, closures y scope.
- Ejercicio 18: Utilizamos Bootstrap para la manipulación del DOM.
